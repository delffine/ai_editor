# Недельный отчёт ИИ-редактора

Отчёт — 10–11 слайдов 16:9 в PDF, как `docs/ai_editor_week_*.pdf`. **Цифры считают
скрипты, слова пишешь ты** — только по этим цифрам и логам, без догадок о причинах.

## Шаги

Рабочая папка — scratchpad (не проект). `<S>` = `.claude/skills/weekly-report/scripts`.

1. **Неделя.** Понедельник нужной недели (по умолчанию — текущая; прогоны идут пн–пт).
   Если неделя ещё идёт, отчёт будет «данные до …» — скажи об этом пользователю.
2. **Данные:** `AI_EDITOR_SSH=deploy@<VPS> python <S>/fetch_data.py <понедельник> <папка>` — архив страниц с VPS
   (+ последняя страница перед понедельником: её предложения — переходящие), логи
   прогонов и рерайта, лента сайта. Нужен ключ `~/.ssh/ai_editor_deploy`; секретов не трогает.
3. **Цифры:** `PYTHONIOENCODING=utf-8 python <S>/analyze.py <папка>` → `stats.json`.
   Проверь вывод на здравый смысл: `pages` ≈ 140 за неделю, `site_week` ≈ 100,
   `taken_rows` — каждая взятая новость с предложением (`prop` не пустой). Если
   скрипт предупредил, что лента сайта не покрывает неделю, — увеличь `limit` в `fetch_data.py`.
4. **Тексты:** `python <S>/render.py <папка> --init` → `narrative.json` с TODO. Заполни,
   опираясь на `stats.json` (в т. ч. `skipped_samples`, `taken_rows`, `urgent_titles`,
   `runs_fail`), логи в `<папка>/logs/`, README.md и история коммитов `git log`
   (что поменялось за неделю — раздел `changes`, по датам):
   - каждое утверждение — с цифрой из `stats.json`; причин, которых нет в данных, не
     придумывай («редакция не успела», «потому что правило…» — только если это видно);
   - сравнение с прошлой неделей скрипт строит сам из `docs/stats_*.json` — в
     `notes.compare` объясни главное отличие;
   - `notes.fails` — что за сбои по логам (`runs_fail` + текст ошибки в логе);
   - выводы (`conclusions`): 4–6 пунктов «что работает / что подкрутить», каждый —
     `["Жирное начало:", "продолжение с цифрой"]`;
   - заголовки — утверждение-вывод, не название раздела; падежи и числа проверь.
5. **PDF:** `python <S>/render.py <папка> docs` → `docs/ai_editor_week_<пн>_<ММ-ДД>.pdf`,
   `docs/stats_<пн>.json` (база для сравнения в следующий раз) и `slide_NN.png` в папке.
   **Посмотри каждый `slide_NN.png`** (Read): текст не вылезает за слайд, подписи не
   наезжают. Длинную заметку сократи в `narrative.json` и пересобери.
6. Отдай пользователю путь к PDF и 3–4 главных цифры.

## Как считается (чтобы объяснять)

- «Разобрано» = предложено + отсеяно (раздел «Отсеяно в этом прогоне»; вытесненные
  лимитом свои предложения считаются отдельно).
- «Взято» — список «Редакция взяла наши предложения» на страницах: снято за неделю и
  вышло на сайте на этой неделе. Переходящие (были на последней странице прошлой недели)
  входят в «совпало с сайтом», но не в «взято из предложений недели».
- Опережение — pubDate новости сайта минус первое появление предложения на странице.
- Причины отсева и тип источника — по ключевым словам (`reason_kind`, `src_kind` в
  `analyze.py`), погрешность ±5–10%. Если категория «PR, анонсы…» распухла — посмотри
  `skipped_samples` и поправь регулярки.
- Стоимость — сумма `cost` из логов (отбор + рерайт/фактчек), эквивалент цены API.
